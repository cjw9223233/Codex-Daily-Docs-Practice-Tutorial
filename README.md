# Codex 每日 Docs 實務教學

每天約 30 分鐘，透過繁體中文教材與實作案例，練習把 ChatGPT／Codex 用在程式開發與日常工作。

適合已使用過 AI 對話、但還不熟悉如何提供脈絡、驗證結果與管理工具的讀者。從第 1 課開始即可，不必先懂所有開發工具。

## 5 分鐘快速開始

1. 開啟 [第 1 課：把模糊需求寫成可驗證的程式任務](2026-09-21-lesson-01-把模糊需求寫成可驗證的程式任務.md)。
2. 先看目標與 Demo 情境，再把教材的「可複製提示詞」及範例資料貼到 ChatGPT 或 Codex。
3. 比較 AI 的回答與教材的預期結果；有程式時，依該課指示執行。
4. 完成練習，用自我檢查標準確認成果，再前往下一課。

只閱讀教材不需安裝 Node.js。若使用 VS Code 開啟 `.md`，可按 `Ctrl+Shift+V` 預覽排版；也可以使用支援 Markdown 的閱讀器。

## 每堂課怎麼學

| 時間 | 建議活動 |
| --- | --- |
| 5 分鐘 | 閱讀目標與核心觀念 |
| 15 分鐘 | 複製提示詞、跟做 Demo、核對結果 |
| 8 分鐘 | 完成練習及自我檢查 |

實際分段以各課安排為準。尚未完成上一堂練習，也可以先閱讀下一堂。

每課通常包含學習目標、觀念與使用時機、最佳實踐、完整 Demo、練習、驗收標準、下堂預告與官方來源。程式與資料多為自製教學案例；教材會區分「實際執行」和「預期／模擬」結果。

## 如何執行程式 Demo

依教材指定的語言與環境操作。例如第 26 課的 JavaScript 可從 Markdown 複製到自己的練習資料夾，儲存為 `lesson26-demo.js`。

若電腦已安裝 Node.js，在練習資料夾開啟 PowerShell：

```powershell
node --version
node .\lesson26-demo.js
```

第 26 課的比較版預期顯示 `PASS: 11 checks`，接著輸出網頁與批次報價結果。如果出現「找不到 node」，表示目前環境無法使用該指令；可依教材提供的瀏覽器 Console 替代方式跟做。

這個儲存庫以教材為主。獨立 `.js` 檔可能未隨教材存入，完整程式請以各課 Markdown 為準；不需要先執行 `npm install`。程式語法、依賴和驗證方式則依個別課程說明。

## 檔案與儲存方式

```text
Codex 每日 Docs 實務教學/
├── README.md
├── YYYY-MM-DD-lesson-NN-主題.md
├── lesson18-demo-report.md
└── .git/                          # Git 管理的歷史資料
```

- `YYYY-MM-DD`：教材日期，使用台北時間。
- `NN`：課次，依實際產出接續。日期可能不連續，請按課次閱讀。
- `.md`：UTF-8 Markdown 純文字文件，可用編輯器閱讀及修改。

此使用者環境的教材首選位置是 `D:\Downloads\Codex 每日 Docs 實務教學`。若寫入失敗，排程會嘗試存到 `C:\Users\cjw\Documents\Codex\2026-09-18\chatgpt\outputs`，並將待搬資訊記在備援目錄的 `docs-pending-moves.json`。

補搬工作只處理待搬清單：複製後確認來源、目的與記錄的 SHA-256 一致，才刪除來源。同名但內容不同會保留來源並回報。SHA-256 是用來核對檔案內容是否一致的摘要值。

## 新手 Git 日常操作

Git 用來記錄檔案變更，讓你能查看差異與回顧歷史。在這個儲存庫資料夾開啟 PowerShell 後，可以使用：

```powershell
# 查看新增與修改的檔案
git status

# 查看已追蹤檔案尚未暫存的內容差異
git diff

# 將 README 納入下一次提交
git add -- README.md

# 儲存這次變更到本機歷史
git commit -m "docs: add beginner README"
```

`git diff` 不會顯示尚未追蹤的新檔內容，新教材請先直接開啟檢查。新增教材時，把 `git add` 後的檔名換成該教材檔名；檔名有空白時請加雙引號。

`commit` 記錄在本機，`push` 才會送到已設定的遠端儲存庫。是否有遠端可用 `git remote -v` 查看；本 README 不假設你已設定 GitHub 或其他遠端。README 建立作業也不會替你自動提交或推送。

## 常見問題

**剛開始不會寫程式，可以學嗎？**  
可以先練習提示詞、需求與驗收。遇到語法時，請 AI 以該課範例解釋，再用實際結果核對。

**AI 說測試通過，就算完成了嗎？**  
請確認實際執行的指令、結果與涵蓋範圍。「預期結果」可以幫助跟做，但不等於已執行的證據。

**今天的課程不在 D 槽？**  
先看當日對話的實際儲存位置，再檢查備援目錄與待搬清單；若兩處都寫入失敗，教材應在對話中交付。不要只憑訊息中的預定路徑判斷已存檔。

**為什麼別人的電腦沒有這些路徑？**  
C、D 槽路徑是目前使用者的設定。複製儲存庫後可從自己的資料夾閱讀，README 的教材連結使用相對路徑。
